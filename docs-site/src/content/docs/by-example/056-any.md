`Any` (ADR-0076) is a value whose type travels with it, so a procedure can take an argument whose
type it does not statically know and read it back safely. It is the second half of runtime type
information, built on `type_info`.

- `any_of(*x)` **erases**: it builds `Any{type, data}` where `type` is a `*Type_Info` describing
  `x` and `data` points at `x`.
- `any_as(a, T)` **recovers**: it checks the `Any`'s type is `T` and returns the value, or
  **traps** if it is not.

```jr
#import "Basic";

/// Two fields, so a transposed read would put a value in the wrong place.
Point :: struct {
    x: s64;
    y: s64;
}

/// A different struct with the *same shape*, which is what makes the identity check earn its keep.
Pair :: struct {
    a: s64;
    b: s64;
}

/// Reads an `Any` it is told holds a `Point`, and sums it.
sum_point :: (a: Any) -> s64 {
    p := any_as(a, Point);
    return p.x + p.y;
}

main :: () {
    n := 0;

    // Round-trip a struct through `Any` and back.
    p: Point;
    p.x = 3;
    p.y = 4;
    a := any_of(*p);
    q := any_as(a, Point);
    if q.x == 3 { n = n + 1; }
    if q.y == 4 { n = n + 2; }

    // Through a procedure that took the `Any` without knowing its type.
    if sum_point(a) == 7 { n = n + 4; }

    // The implicit coercion: `*p` is a `*Point`, and `sum_point` wants an `Any`.
    if sum_point(*p) == 7 { n = n + 512; }

    // The `type` field is a real `*Type_Info`, readable through the `Any`.
    if a.type.size == 16 { n = n + 8; }
    if a.type.kind == Type_Info_Kind.STRUCT { n = n + 16; }

    // A builtin erased and recovered — the path that has no declaration.
    m: s64;
    m = 99;
    b := any_of(*m);
    r := any_as(b, s64);
    if r == 99 { n = n + 32; }
    if b.type.id == type_info(s64).id { n = n + 64; }

    // `Point` and `Pair` are the same shape but different types: their `id`s differ.
    ip := type_info(Point);
    ir := type_info(Pair);
    if ip.id != ir.id { n = n + 128; }

    // Every assertion: 767 (255 + the 512 coercion bit).
    if n == 767 {
        exit(0);
    }
    exit(1);
}
```

## The erasing conversion is allowed only here

`any_of(*p)` turns a `*Point` into the `*u8` that `Any.data` holds. A bare `cast(*u8, p)` stays
**refused** — a general pointer cast would make every pointer type interconvertible, so a wrong
pointee type would become a silent wrong read. Nothing is actually reinterpreted: a pointer's bits
do not depend on its pointee, so the erasure emits no code.

There is also an **implicit coercion** (ADR-0076 §1): because `sum_point` wants an `Any`, passing a
`*Point` erases it at the call, exactly as `any_of` would explicitly. So `sum_point(*p)` and
`sum_point(any_of(*p))` are the same call — the `512` bit above checks this ergonomic half.

## The read-back is checked by identity, not by pointer

`any_as` cannot compare `*Type_Info` pointers, because two `type_info(T)` calls have different
addresses (each spills its own slot). Instead every type carries a `Type_Info.id` — the type's
pool id, the identity the whole compiler already uses, and identical in both engines because they
share one pool — and `any_as` compares *that*.

Comparing by `name` would be **unsound**: a local `Point` and an imported one share a name but are
different types (ADR-0015 §1). This is exactly what `Point` and `Pair` above demonstrate: same
shape (two `s64`s, size 16, align 8), so `size`/`alignment`/`kind` cannot tell them apart — only
`id` can, and `ip.id != ir.id` is the assertion that proves it.

## A mismatch traps

`any_as(a, Wrong)` **traps**, exactly as reading the wrong case of a tagged `variant` does
(ADR-0068 §4): a tag says which read is valid, and the wrong one traps rather than reinterpreting.
The check is the whole point — a read that ignored the type would make `Any` a `void*` with extra
steps.

That trapping path is *not* in this corpus file: a trap aborts the process, which a file that must
exit `0` cannot show, so it is exercised in the engine's differential tests instead. Here every
`any_as` matches its type.

## Observing the result

Nine assertions sum to `767`. The `exit` value encodes which held, so `jr run` and `jr build` can
be asserted to agree byte-for-byte — and the native engine has to materialise a `Type_Info`, erase
a pointer and read it back, all of which could fail independently of the VM.
