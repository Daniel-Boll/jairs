Jairs' documentation is three books. They cover the same language from three angles, and
they are meant to be used differently.

## Book I — The Jairs Language

A **narrative tour**, written in the spirit of *The Rust Programming Language*. It starts
with a program you can run and builds up the whole language one concept at a time:
values, declarations, procedures, control flow, the type system, memory, modules,
compile-time execution, reflection, polymorphism, and metaprogramming.

Read this first if you are new to Jairs. Each chapter assumes the ones before it, and the
examples grow with you.

[Start reading →](/language/introduction/)

## Book II — Jairs by Example

A **reference by example**. Every feature is a small, self-contained, annotated program —
the same programs the compiler uses as its own test corpus, so the syntax is always exactly
what the compiler accepts. There is no narrative thread; each page stands alone.

Reach for this when you already know roughly what you want and need the precise spelling,
or when you want to see one feature in isolation without the surrounding prose.

[Browse the examples →](/by-example/)

## Book III — Jairs in Practice

**Whole programs that do something.** A word-frequency counter, a fixed-capacity stack, a
generic hash-map cache, a deterministic simulation driven by a seeded PRNG, a vector-math
sketch, and a serialiser generated by the note-driven metaprogram loop. Each is walked
through end to end, showing how the pieces from Book I compose into a real program.

Read this when you want to see the language carry its own weight, or when you are looking
for a pattern to copy.

[See the programs →](/in-practice/)

## A word on scope

Jairs is pre-alpha and deliberately small. These books describe **what exists today**. When
something is not yet in the language, the text marks it <span class="jairs-status absent">absent</span>
and names the wave that adds it, rather than pretending. That honesty is the point: you can
trust that anything shown without a caveat actually runs.
